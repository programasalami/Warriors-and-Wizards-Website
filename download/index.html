Download Warriors & Wizards

Free. Run the launcher once: it installs the game, adds a shortcut, and keeps everything up to date from then on.

Windows

Download for Windows

Open WaWLauncher.exe, pick a folder, press Install.

If Windows says it "protected your PC", click More info, then Run anyway (the game is not code-signed yet).

Linux

Download for Linux

Extract it, then start WaWLauncher (double-click, or ./WaWLauncher in a terminal).

64-bit, with an X11 or XWayland session. No root needed.

Can't install anything on this computer? Play the web version
System requirements
  • Windows: 64-bit Windows 10 or 11.
  • Linux: 64-bit, X11 or XWayland, Mesa 19+ or the NVIDIA driver.
  • Graphics: OpenGL 4.3, which is almost anything from 2013 on (Intel HD 4400 laptops included).
  • Space: about 150 MB. Memory: 4 GB.
  • Web version: any current browser with WebGL2 (Chrome, Edge, Firefox, Safari 15+).
