Download Warriors & Wizards

Windows

Download for Windows

Open WaW-Installer.exe, pick a folder and press Install. The launcher opens, downloads the game and lets you sign in. Then press Play.

If Windows says it "protected your PC", click More info, then Run anyway (the game is not code-signed yet).

Linux

Download for Linux

Extract it and start WaW-Installer (double-click, or ./WaW-Installer in a terminal). Pick a folder, press Install; the launcher opens, downloads the game and lets you sign in.

64-bit, with an X11 or XWayland session. No root needed.

Play the Web Client
System requirements
  • Windows: 64-bit Windows 10 or 11.
  • Linux: 64-bit, X11 or XWayland, Mesa 19+ or the NVIDIA driver.
  • Graphics: OpenGL 4.3, which is almost anything from 2013 on (Intel HD 4400 laptops included).
  • Space: about 150 MB. Memory: 4 GB.
  • Web Client: any current browser with WebGL2 (Chrome, Edge, Firefox, Safari 15+).

Having trouble with the launcher?

Windows says "Windows protected your PC"

The launcher isn't code-signed yet, so Windows doesn't recognise it. Click More info, then Run anyway. You only have to do this once.

My antivirus removed or blocked the launcher

Unsigned programs sometimes get flagged. Restore WaW-Installer.exe or WaWLauncher.exe from your antivirus's quarantine and allow the folder you installed the game in, then start the launcher again.

The launcher won't update the game

The launcher looks for updates every time you open it and again when you press PLAY. When one is out, the big button says UPDATE. It can't replace the game's files while the game is running: close the game, then press UPDATE again.

The game crashes or won't start

Press Repair in the launcher. It checks every game file and downloads again any that are missing or damaged. Your settings are kept.

The game says "Update required"

A new version came out while you were playing. Close the game and start it from the launcher, which downloads the update first. In the Web Client, press Refresh.

Where did the game install? Can I move it?

The launcher goes in the folder you picked the first time, and the game goes in a Game folder inside it. To move it, move the whole folder, launcher included, and update your shortcuts.

Do I have to sign in every time?

No. Tick Remember me on this PC when you sign in, and the launcher keeps you signed in. It never stores your password, only a sign-in key that stops working after 30 days without use, or as soon as you press Sign out. PLAY opens the game already signed in.

How do I uninstall the game?

On Windows, open Settings > Apps, find Warriors & Wizards and choose Uninstall, or press Uninstall at the bottom of the launcher (that one works on Linux too). Your account and characters stay safe on the server.

Linux: nothing happens when I open the launcher

Open a terminal in the extracted folder and run chmod +x WaW-Installer, then ./WaW-Installer (for the installed launcher: ./WaWLauncher in its folder). If it still won't start, the terminal shows why. The launcher needs an X11 or XWayland session.
