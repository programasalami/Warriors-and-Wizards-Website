Get the game

Two ways to play, one account, one world. Your characters are the same whichever you pick.

Windows client

Download for Windows

The full desktop version. Smoother on older PCs and laptops, and it does not depend on your browser.

  • The first start downloads the game (about 150 MB); after that it only checks for updates and starts the game.
  • Windows may show a blue "protected your PC" box the first time because the game is not code-signed yet. Click More info, then Run anyway.
  • Make an account in the game or sign in with the one you use in the browser.

Requirements: 64-bit Windows 10 or 11, a graphics card with OpenGL 4.3 (anything from about 2013 on, including Intel HD 4400). About 150 MB.

Linux client

Download for Linux

The same desktop client for 64-bit Linux. Smoother on older machines, and it does not depend on your browser.

  • Extract the archive anywhere: tar -xzf WarriorsAndWizards-Launcher-linux.tar.gz
  • Start it with bash run.sh the first time; after that ./WarriorsAndWizards works too. It downloads the game, keeps it up to date, and starts it.
  • Needs OpenGL 4.3 (Mesa 19 or newer covers Intel and AMD; NVIDIA's driver too) and an X11 or XWayland session.

There is no installer: extracting the archive is the whole setup, no root needed. Your settings live in ~/.local/share/AlloyClient.

Play in your browser

No download. Opens in Chrome, Edge, Firefox or Safari and plays on the same servers.

Play now

The first load fetches the game once (about 20 MB); after that it starts quickly. Needs WebGL2, which every current browser has.
