System requirements
  • Windows: 64-bit Windows 10 or 11.
  • Linux: 64-bit, X11 or XWayland, Mesa 19+ or the NVIDIA driver.
  • Graphics: OpenGL 4.3, which is almost anything from 2013 on (Intel HD 4400 laptops included).
  • Space: about 150 MB. Memory: 4 GB.
  • Web Client: any current browser with WebGL2 (Chrome, Edge, Firefox, Safari 15+).

Having trouble with the launcher?

Windows says "Windows protected your PC"

The launcher isn't code-signed yet, so Windows doesn't recognise it. Click More info, then Run anyway. You only have to do this once.

My antivirus removed or blocked the launcher

Unsigned programs sometimes get flagged. Restore WaWLauncher.exe from your antivirus's quarantine and allow the folder you installed the game in, then start the launcher again.

The launcher won't update the game

It can't replace the game's files while the game is running. Close the game, then press PLAY again, or close and reopen the launcher.

The game crashes or won't start

Press Repair in the launcher. It checks every game file and downloads again any that are missing or damaged. Your settings are kept.

The game says "Update required"

A new version came out while you were playing. Close the game and start it from the launcher, which downloads the update first. In the Web Client, press Refresh.

Where did the game install? Can I move it?

The game installs in the folder you picked the first time, right next to the launcher. Open game folder in the launcher takes you there. To move it, move the whole folder, launcher included, and update your shortcuts.

Linux: nothing happens when I open the launcher

Open a terminal in the extracted folder and run chmod +x WaWLauncher, then ./WaWLauncher. If it still won't start, the terminal shows why. The launcher needs an X11 or XWayland session.

My problem isn't listed here

Post it on the forums with what you saw and which system you're on. Meanwhile, the Web Client runs in your browser with no install.
